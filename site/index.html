mkdocs-ai-chat

用托管前端和一个轻量 Python 服务，为任何 MkDocs 站点添加基于文档的流式 AI 回答。

立即安装 阅读文档
真实 MKDOCS 页面
录制于 EEnotes。 组件直接运行在现有文档布局中。 流式输出 · 来源链接 · Markdown · LaTeX
无需 Docker 使用普通 Python venv 和 systemd 服务。
托管前端 直接从 GitHub Pages 加载已发布的 JS 和 CSS。
SSE 回答、检索状态和公式都会实时流式显示。
本地记忆 对话历史保存在访问者自己的浏览器中。

改三处配置，装一个服务。

文档就是交互界面。

前端保持轻巧，后端负责检索、上下文和来源质量。

01

Agent 自主检索

模型自行决定检索词，可以多次搜索，并在无需检索时直接回答。

02

真正有用的来源链接

来源会跳到对应标题、保留文字高亮，并在悬停时预览 Markdown 和公式。

03

实时富文本

标题、表格、代码、引用、分割线和 LaTeX 都能在流式回答过程中渲染。

04

留在本地的上下文

多轮历史保存在 localStorage 中，刷新后恢复，并且可在回答过程中清除。

05

为移动端而设计

面板在手机上变为全屏工作区，适配虚拟键盘、安全区域和稳定触控目标。

保留 MkDocs 流程，只添加 AI 层。

组件由 GitHub Pages 发布；API 密钥、索引和文档同步仍然保留在自己的服务器上。
